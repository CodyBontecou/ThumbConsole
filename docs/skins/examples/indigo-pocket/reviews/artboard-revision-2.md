# Canonical artboard amendment — revision 2

Visual critique exposed a native-frame collision in the generated portrait SNES layout: the top-bar system control overlapped the upper action control, making a complete active ring and role separation impossible through passive artwork.

Canonical template revision 2 keeps every interactive control unchanged and moves only the passive portrait system toggle into the nearest collision-free center lane (`centerY = 0.32`). The system frame is now approximately x 171–231 px, y 258–302 px on the 402×874 artboard. New SNES profiles carry template revision 2; revision-1 profiles intentionally fail exact template compatibility and fall back to semantic materials without aligned canvas artwork.

Indigo Pocket’s concept and acceptance criteria remain unchanged. The portrait artwork must remove the obsolete action-harbor notch and provide an indigo index cradle around the revision-2 system frame.
